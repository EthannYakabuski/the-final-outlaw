THE FINAL OUTLAW — CORE DESIGN AND HANDOFF

Portrait Android primary; Web fallback. Godot 4.5.1 GL Compatibility.
Left-thumb movement and deliberate gun-button firing, with nearest-visible-foe aim assistance. No automatic firing.20-round base magazine; manual/empty-trigger reload; DASH grants brief invulnerability. Keyboard WASD/arrows, J to fire, R to reload, Space, Escape. Settings independently mute music and effects. Readable enemy bullets, health, telegraphed hazards, collectible hearts/shields/rapid-fire/fan-shot.

100 explicit campaign entries live in game/campaign.json; the shipped game never generates campaign missions at runtime. Ten chapters have different rosters, hazards, palettes, and active combat modifiers. Each entry specifies a unique geometry layout, goal, numerical wave schedule, roster, spawn gaps, difficulty and deadline. First two teach steering, deliberate fire/reload and dash/survival. Five goal types: eliminations, timed survival, retrieve supplies, hold a circle, guardian duel. Wave budgets guarantee enough eliminations/crates for the goals. Finite waves also give struggling players breathing room. Enemy health, speed and damage scale with difficulty. Endless mode has unlimited spawning, increasing stats/cadence and a score record.

Each campaign victory earns 1-3 stars according to remaining health. Completion sequentially unlocks the next trail. Replays retain the best star count; first-clear coin/XP rewards exceed replay rewards. Seven gear tracks each have eight upgrades: power, health, boots, magazine, reload, dash and armor. New keys default to zero when loading real version1 saves. Player XP levels, daily gifts (35/45/60/75/95/125/200 coins) and three quests work locally without service IDs. Daily boundaries use UTC; clock rollback cannot re-claim a previous day, but this is an offline game, not an anti-cheat system. Local JSON saves keep one prior valid backup and clamp loaded values. Save on round completion, app pause/close and periodically. No cloud-save claims.

SERVICE CONTRACT
Optional /root/Services supplies set_menu_visible, round_finished, reward_requested(context,callback(bool)), unlock, submit, open_achievements, open_leaderboards, sign_in, privacy_options, can_reward, status. Core runs when autoload is absent. Home/menu banner and every-two-round interstitial cadence are platform responsibilities. A continue restores 65% health and can happen once per failed run; an optional camp crate gives120coins once per UTC day. Rewards require a true earned callback; Web/offline ad unavailability never manufactures an entitlement. Catalog game/catalog.json lists symbolic achievement/board keys, display names, metrics and thresholds for native ID mapping and marketing icons. Android backend IDs, account/signing setup and final human service testing remain pending root/user integration.

QA / CAPTURE
Run tests with --headless --path <project> --script res://tests/test_models.gd. Run --headless --path <project> -- --smoke-test for the scene smoke test. Use a normal rendered Godot launch with -- --capture=home|map|brief|play|workshop|rewards|records --capture-level=10 --capture-path=<absolute.png>. Captures use actual game scenes. Capture mode uses fresh unsaved progression and bypasses campaign unlocking only to open the requested QA level; it does not write player saves. Web has optional Android-only service screens disabled/unavailable. Actual Android/Web builds and device/store/service evidence are supplied by the coordinating integration agent; core test results alone do not verify those platforms.

ROUND TWO WORLD / COLLISION
Town definitions are explicit in arena_layouts.json; town.gd exposes shared parcel geometry. Six stronger archetypes navigate a10px actor-clearance AStar grid, refresh routes around buildings and only shoot through clear sight lines. Swept bullet segments resolve the first cover/actor hit, including at close contact. Twelve supplied monster sheets retain original dimensions/frame data and custom non-CC0 terms. All original campaign IDs/rewards/service keys remain stable.
